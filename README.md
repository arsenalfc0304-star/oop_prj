# Проект oop_prj

## Описание:

Проект oop_prj - это приложение на Python для реализации в сфере E-commerce.

## Установка:

1. Клонируйте репозиторий:
```
git clone git@github.com:arsenalfc0304-star/oop_prj.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
## Использование:
ВНИМАНИЕ: ПРИЛОЖЕНИЕ НАХОДИТСЯ В ПРОЦЕССЕ РАЗРАБОТКИ!

### модуль *category.py*:
Создан класс *Category*, для него определены следующие свойства:
название (name),
описание (description),
список товаров категории (products).

### модуль *product.py*:
Создан абстрактный класс *BaseProduct*, для него определены методы,
обязательные для применения в дочерних классах.

Создан класс *PrintMixin*, который выводит в консоль информацию о вновь созданном продукте.

Создан класс *Product*, дочерний для *BaseProduct*, для него определены следующие свойства:
название (name),
описание (description),
цена (price),
количество в наличии (quantity).

Создан класс *Smartphone*, дочерний для *Product*, для него дополнительно определены следующие свойства:
производительность (efficiency),
модель (model),
объем встроенной памяти (memory),
цвет (color).

Создан подкласс *LawnGrass*, для него дополнительно определены следующие свойства:
страна-производитель (country),
срок прорастания (germination_period),
цвет (color).

## Тестирование:
Для тестирования выполните в командной строке команду *pytest*.
