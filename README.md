# Проект oop_prj

## Описание:

Проект oop_prj - это приложение на Python для реализации в сфере E-commerce.

## Установка:

1. Клонируйте репозиторий:
```
git clone git@github.com:arsenalfc0304-star/oop_prj.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
## Использование:
ВНИМАНИЕ: ПРИЛОЖЕНИЕ НАХОДИТСЯ В ПРОЦЕССЕ РАЗРАБОТКИ!

### модуль *category.py*:
Создан класс Product, для него определены следующие свойства:
название (name),
описание (description),
список товаров категории (products).

### модуль *product.py*:
Создан класс Product, для него определены следующие свойства:
название (name),
описание (description),
цена (price),
количество в наличии (quantity).

## Тестирование:
Для тестирования выполните в командной строке команду *pytest*.
Реализованы модули:
*test_category.py*,
*test_product.py*.
